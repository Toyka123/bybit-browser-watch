# Bybit Browser Watch

Bybit Live с проверкой подключения при включении. В живом режиме бот берёт реальные свечи и спреды Bybit (через ваш браузер, т.к. Bybit гео-блокирует серверные IP) — весь анализ, сигналы и проверки SL/TP идут уже по настоящему рынку, биржа отображается в шапке и на графике. API-ключи для мониторинга не нужны — они понадобятся только если позже включим отправку реальных ордеров.
